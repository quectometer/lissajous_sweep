X は下の図と横軸を、Y は右の図と縦軸を共有。点線をたどると、同じ時刻の入力が XY の1点になります。

見方と操作のヒント

正弦波：x(t) = Aₓ sin(ωₓt + φₓ)、y(t) = Aᵧ sin(ωᵧt + φᵧ)。振動数 f = ω / 2π です。X と Y を同じ振動数にして位相差を変えると、直線・楕円・円の違いを観察できます。

鋸歯状波：一定速度で増加し、+A から −A へ戻ります。X を鋸歯状波にすると、横方向の掃引と Y 入力の関係が見えます。戻る瞬間の線は描きません。

三角波・矩形波：三角波は一定の速さで増減し、矩形波は2つの値を交互にとります。正弦波と切り替えて、入力波形の形が XY の軌跡にどう現れるか比較できます。

ノイズ付き正弦波：「波形・振幅」を開くと、ノイズ量を調整できます。「ノイズを変える」で別のノイズへ切り替えられます。ノイズが加わると同じ軌跡を周期的に繰り返さなくなるため、一周表示と全体の参考線は利用できません。ノイズ量を 0 にすると正弦波として扱います。

一周：動く2入力の位相が初めて同時に戻る共通周期 T です。振動数比 fₓ : fᵧ = p : q（既約）のとき T = p/fₓ = q/fᵧ。一周モードでは T で停止し、結果を残します。p, q がともに64以下で一致する比を判定します。近い比を無理に閉曲線とは扱いません。

操作：数値は入力後に Enter または欄の外を押すと確定します。±0.1 は表示中の単位で増減します。波形・振幅・振動数・位相を変えると t = 0 へ戻ります。速度・時間幅・配色の変更では時刻を維持します。設定画面に移ると一時停止します。

時間軸：X 入力では下向き、Y 入力では右向きに時間が進みます。両方とも同じ時間範囲で、目盛りは開始からの秒数です。スペースキーで再生／停止（入力欄の操作中を除く）。別タブに移った間はシミュレーション時間を進めません。
